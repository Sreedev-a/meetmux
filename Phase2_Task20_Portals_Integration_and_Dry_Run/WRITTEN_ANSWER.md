# Portals Integration & Dry Run

I validated recommendation v1 on labeled portal-shaped results using NDCG@3, Recall@3, catalog coverage, empty-result rate, and segment-level NDCG. The release gate requires aggregate NDCG/recall at least 0.75, coverage at least 0.95, and every segment at least 0.70 NDCG. The executed report passes every gate and retains per-user evidence for diagnosis.
