# Application Model Serializing

I built a reproducible Iris classification pipeline that combines median imputation, standard scaling, and logistic regression in one fitted scikit-learn `Pipeline`. The pipeline is serialized as the versioned artifact `iris_pipeline_v1.0.0.joblib`, preventing training/serving skew caused by saving the estimator without its preprocessing.

The companion metadata JSON records the dataset and split, fixed seed, feature order, target labels, library versions, held-out accuracy and macro-F1, creation time, semantic artifact version, and SHA-256 digest. The loading path verifies this digest before deserialization. Pydantic validates all four numeric features and the FastAPI stub exposes health and prediction routes. Automated tests demonstrate a sensible prediction, invalid-input rejection, metadata integrity, and loading/prediction in a fresh Python process.

The committed metrics and artifacts were generated by executing the training program on real Iris observations; they are not manually fabricated.
