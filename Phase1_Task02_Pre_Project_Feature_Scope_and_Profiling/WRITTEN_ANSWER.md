The modelling problem was scoped as predicting whether each breast-mass sample is malignant or benign from 30 quantitative nuclear-image measurements in the real scikit-learn Wisconsin Breast Cancer dataset. The target was defined precisely as 0 = malignant and 1 = benign, with malignant-class recall selected as the primary metric and F1, precision, ROC-AUC, and accuracy retained as secondary measures. All 30 candidate features were profiled for type, missingness, uniqueness, ranges, and quality; the dataset contains 569 rows, no missing values, and no duplicate complete rows. Leakage checks excluded the target from predictors and found no direct target copies, suspicious outcome fields, or post-outcome features, so all 30 predictors were vetted. Class balance was 212 malignant (37.26%) and 357 benign (62.74%). A fixed-seed stratified 398/85/86 split was created. The most-frequent baseline achieved 62.79% test accuracy but 0.00 malignant recall, supporting a GO decision for controlled baseline modelling, not clinical deployment.
