# Payments Design & Gateway Setup

I recorded a versioned pre-paywall match-quality baseline from labeled impressions. The evaluation reports NDCG@3, Precision@3, Recall@3, and MRR for each query and macro averages, providing a reproducible reference before monetization can influence user behavior. The raw labels, executable evaluator, generated report, and edge-case tests are included so later changes can be assessed against the same definitions.
